Amma Nursing Care Website
Responsive, colourful website for Amma Nursing Care.
Publish on GitHub Pages
Create a new public repository named amma-nursing-care.
Upload index.html and the full assets folder (keep the folder structure).
Open Settings → Pages.
Under Build and deployment, select Deploy from a branch.
Choose branch main and folder /(root), then click Save.
Wait for GitHub Pages to publish the site; the public address appears in the Pages section.
Phone numbers, service descriptions and other text can be edited in index.html.
